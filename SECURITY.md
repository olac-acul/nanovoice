# Security policy

Please report vulnerabilities **privately**: use "Report a vulnerability" in the Security tab of this repository
(GitHub private vulnerability reporting). Do not open a public issue for a security problem.

What matters most here: the app can act on the phone for an agent (timers, calls, links, calendar changes), so a
way to make it run an action nobody asked for, to read private data without the person's setting being on, or to
send the server token anywhere else is a security problem.

You can expect an answer within a week. This is a personal project maintained in spare time: there is no bounty.
